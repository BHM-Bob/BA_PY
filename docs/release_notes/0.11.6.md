# Release Notes – `mbapy` Library  
**Version:** 0.11.6  
**Release Date:** 2026-07-11  
**Maintainer:** BHM-Bob  

---

## Overview
This release consolidates **38 commits** spanning from 2025-12-14 to 2026-07-11.  
The focus is on **TaskPool enhancements**, **file operation improvements**, **new CLI scripts**, **Python 3.14 compatibility**, and **dependency updates**.  
All changes are backward-compatible unless explicitly noted.

---

## 🚀 New Features

### Task Management
- **`mbapy.web_utils.task.MultiQueue`** *(new)*  
  Added multi-queue scheduling class with round-robin put/get methods supporting timeout and blocking configuration. Includes qsize/empty/full status query methods.

- **`TaskPool.get_task_elapsed()`**  
  Added task execution time statistics function returning max, min, and average elapsed time for performance monitoring.

- **`TaskPool.mp_pool_init_kwargs`**  
  Added optional parameter for custom multiprocessing pool initialization arguments.

- **`TaskPool.pull_task()`**  
  Added method for retrieving tasks directly from the result queue.

### File Operations
- **`mbapy.file.ProgressFileWrapper`** *(new)*  
  Added class for wrapping file objects with progress bar updates during file operations.

- **`mbapy.file.copy_file_with_progress()`** *(new)*  
  Added function for file copying with tqdm progress bar display.

### CLI Scripts
- **`mbapy.scripts.till.py`** *(new)*  
  Added script for waiting until specific conditions are met before proceeding, useful for scheduling tasks, resource management, and synchronization.

- **`mbapy.scripts.extract_pdf_toc.py`** *(new)*  
  Added script for extracting PDF table of contents and converting to markdown format.

## ⚙️ Improvements

### Task Management
- **`TaskPool`**  
  - Added thread lock protection for shared `_task_elapsed` data  
  - Added execution time recording in both async and process modes  
  - Added repeat start check for the `start()` method  
  - Enhanced `close()` method to properly wake condition variables for clean shutdown

### File Operations
- **`mbapy.scripts.copy_file.py`**  
  Added `--show-progress` parameter for displaying file copy progress and speed.

- **`mbapy.scripts.move_file.py`**  
  Added `--show-progress` parameter for displaying file move progress and speed.

- **`mbapy.scripts.remove_file.py`**  
  Added `-l` option to list all files to be deleted before performing the operation.

- **`mbapy.scripts.find_file.py`**  
  - Added `--sort-by-size` parameter for sorting results by file size  
  - Added `create_size_bins()` and `display_size_distribution()` functions for file size statistics  
  - Optimized output format to display average file size and clearer file information

- **`mbapy.file.opts_file()`**  
  Changed default `way` parameter from `str` to `auto` for automatic file type detection based on extension.

- **`mbapy.file.get_paths_with_extension()`**  
  Changed `c_version` default value to `True` for improved performance and fixed `neg_name_substr` parameter passing in recursive calls.

### CLI Tools
- **`mbapy.scripts.batch_cmd.py`**  
  - Added interactive command line input support with history using `prompt_toolkit`  
  - Added directory path quoting for proper shell handling

### Documentation
- **`docs/web_utils/task.md`**  
  Updated with complete TaskPool documentation including overview, parameters, methods, and usage examples.

- **`docs/build.md`** *(new)*  
  Added build documentation for the project.

- **`docs/scripts/batch_cmd.md`** *(new)*  
  Added documentation for the batch command script.

- **`docs/scripts/till.md`** *(new)*  
  Added documentation for the till script.

- **`TaskPool.wait_till_free()`**  
  Fixed incorrect parameter order for `update_result_queue` parameter.

- **`mbapy.web_utils.spider.Actions`**  
  Added `report_error` parameter for TaskPool integration.

### File Operations

- **`mbapy.scripts.find_file.py`**

### Type Checking

## 🔧 Build & Configuration

### Dependency Updates
- **PyPDF2 → pypdf**  
  Replaced deprecated PyPDF2 dependency with actively maintained pypdf library across `extract_pdf_toc.py` and `paper_parse.py`.

- **prompt_toolkit**  
  Added as dependency for interactive command line input in `batch_cmd.py`.

- **pygame**  
  Moved from game group to main dependencies, then reverted to game/full groups with try-catch import handling.

### Python Version Support
- **Python 3.14**  
  Updated codebase for Python 3.14 compatibility:
  - Replaced deprecated `pkgutil.find_loader()` with `importlib.util.find_spec()`  
  - Added `spec.loader` None check in module loading  
  - Updated type annotations and removed deprecated constructs

### Packaging
- **`pyproject.toml`**  
  - Added `mbapy_lite` to packaging configuration  
  - Removed redundant `packages` configuration  
  - Updated dependency groups for game and full installations

- **`MANIFEST.in`**  
  Excluded test directory and its subdirectories from package distribution.

- **`setup.py`**  
  Updated to reflect Python 3.14 support and dependency changes.

## 📊 Performance Highlights

This release introduces several performance and usability improvements:
- **Task execution monitoring** with elapsed time statistics for TaskPool operations
- **Progress bar support** for file copy and move operations using tqdm
- **Automatic file type detection** in `opts_file()` reducing manual configuration
- **MultiQueue scheduling** for improved task distribution across multiple queues

---

## 🔄 Migration Notes

- **`opts_file()` default behavior change**: The `way` parameter now defaults to `auto` instead of `str`, automatically detecting file types based on extensions. This is backward-compatible for files that were previously working correctly.
- **Python 3.14 compatibility**: Code updated to work with Python 3.14 while maintaining compatibility with earlier versions.
- **PyPDF2 users**: Projects using `mbapy.sci_utils.paper_parse` or `mbapy.scripts.extract_pdf_toc` will now use pypdf instead of PyPDF2.
